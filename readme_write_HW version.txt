Важный нюанс при записи через J-Link Commander (JLink.exe): область UICR на nRF52832 по умолчанию защищена от записи 
контроллером флеш-памяти NVMC. Если выполнить просто w4 0x10001080, 0xDA000100 без разблокировки NVMC->CONFIG (0x4001E504)
, запись молча проигнорируется.

Выполни в консоли JLink.exe по порядку:

Plaintext
connect
w4 0x4001e504, 1
w4 0x10001080, 0xDA000100
w4 0x4001e504, 0
mem32 0x10001080, 1
r
g
Проверка: команда mem32 0x10001080, 1 должна вернуть 10001080 = DA000100, а после перезапуска (r, g) и переподключения 
в приложении RaceDAQ_cfg отобразится HW V0.1.0. 
(Если используешь nrfjprog -f nrf52 --memwr 0x10001080 --val 0xDA000100, он включает NVMC автоматически).
