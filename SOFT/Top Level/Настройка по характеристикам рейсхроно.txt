========================================================================
       ШПАРГАЛКА КАНАЛОВ RACEDAQ ДЛЯ ПРИЛОЖЕНИЯ RACECHRONO DIY
========================================================================
Где настраивать в RaceChrono:
Settings -> Vehicle profile -> CAN-Bus Channels -> Add channel

Примечание по Packet ID (PID):
В зависимости от настроек приложения вводите либо Hex (например, 0x100),
либо обычное десятичное число (например, 256).

------------------------------------------------------------------------
ПАКЕТ 0x100 (PID: 256) — АНАЛОГОВЫЕ ВХОДЫ (НАПРЯЖЕНИЯ И ОМЫ)
------------------------------------------------------------------------

1. Температура воды T_WATR (Напряжение на пине P0.02, клемма X5 пин 3)
   Packet ID : 0x100 (или 256)
   Единицы   : V (Вольты, 0..3.3 В)
   Equation  : bytesToUint(raw, 0, 2) * 0.001

2. Температура воды T_WATR (Сопротивление датчика, подтяжка 1 кОм к 3.3V)
   Packet ID : 0x100 (или 256)
   Единицы   : Ohm (Омы)
   Equation  : 1000.0 * bytesToUint(raw, 0, 2) / (3300.0 - bytesToUint(raw, 0, 2))

3. Температура масла T_OIL (Напряжение на пине P0.03, клемма X5 пин 8)
   Packet ID : 0x100 (или 256)
   Единицы   : V (Вольты, 0..3.3 В)
   Equation  : bytesToUint(raw, 2, 2) * 0.001

4. Температура масла T_OIL (Сопротивление датчика, подтяжка 1 кОм к 3.3V)
   Packet ID : 0x100 (или 256)
   Единицы   : Ohm (Омы)
   Equation  : 1000.0 * bytesToUint(raw, 2, 2) / (3300.0 - bytesToUint(raw, 2, 2))

5. Аналоговый вход 1 - AIN1 (Клемма X5 пин 4, вход 0..5 В, делитель 5.1K/10K)
   Packet ID : 0x100 (или 256)
   Единицы   : V (Вольты)
   Equation  : bytesToUint(raw, 4, 2) * 0.001

6. Аналоговый вход 2 - AIN2 (Клемма X5 пин 9, вход 0..5 В, делитель 5.1K/10K)
   Packet ID : 0x100 (или 256)
   Единицы   : V (Вольты)
   Equation  : bytesToUint(raw, 6, 2) * 0.001


------------------------------------------------------------------------
ПАКЕТ 0x101 (PID: 257) — ТЕРМОПАРА EGT, НАПРЯЖЕНИЕ БОРТСЕТИ И МАСКИ
------------------------------------------------------------------------

7. Температура выхлопа EGT (MAX6675, клемма X5 пины 5 и 10)
   Packet ID : 0x101 (или 257)
   Единицы   : C (Градусы Цельсия, 0..1023.75 C)
   Equation  : bytesToUint(raw, 0, 2) * 0.25

8. Напряжение бортсети / Зажигание IGN (Клемма X2 пин 2, делитель 100K/33K)
   Packet ID : 0x101 (или 257)
   Единицы   : V (Вольты)
   Equation  : bytesToUint(raw, 2, 2) * 0.001

9. Битовая маска цифровых входов (Бит 0 = DIN1, Бит 1 = DIN2)
   Packet ID : 0x101 (или 257)
   Единицы   : число 0..3
   Equation  : bytesToUint(raw, 4, 1)

10. Битовая маска цифровых выходов (Бит 0 = DOUT1, Бит 1 = DOUT2)
    Packet ID : 0x101 (или 257)
    Единицы   : число 0..3
    Equation  : bytesToUint(raw, 5, 1)


------------------------------------------------------------------------
ПАКЕТ 0x102 (PID: 258) — ЦИФРОВЫЕ ВХОДЫ И ВЫХОДЫ (ПОБАЙТНО 0 ИЛИ 1)
------------------------------------------------------------------------

11. Цифровой вход 1 - DIN1 (Клемма X2 пин 7, пин МК P0.11)
    Packet ID : 0x102 (или 258)
    Значения  : 0 = разомкнут, 1 = замкнут на массу
    Equation  : bytesToUint(raw, 0, 1)

12. Цифровой вход 2 - DIN2 (Клемма X2 пин 8, пин МК P0.09)
    Packet ID : 0x102 (или 258)
    Значения  : 0 = разомкнут, 1 = замкнут на массу
    Equation  : bytesToUint(raw, 1, 1)

13. Силовой выход 1 - DOUT1 (Клемма X2 пин 3, ключ VT2, пин МК P0.24)
    Packet ID : 0x102 (или 258)
    Значения  : 0 = выкл, 1 = открыт на GND_OUT
    Equation  : bytesToUint(raw, 2, 1)

14. Силовой выход 2 - DOUT2 (Клемма X2 пин 4, ключ VT3, пин МК P0.18)
    Packet ID : 0x102 (или 258)
    Значения  : 0 = выкл, 1 = открыт на GND_OUT
    Equation  : bytesToUint(raw, 3, 1)

15. Статус включения зажигания - IGN ON (Клемма X2 пин 2, пин МК P0.28)
    Packet ID : 0x102 (или 258)
    Значения  : 0 = выкл, 1 = зажигание включено (> 6 В)
    Equation  : bytesToUint(raw, 4, 1)


------------------------------------------------------------------------
ПАКЕТ 0x103 (PID: 259) — АКСЕЛЕРОМЕТР И РЫСКАНИЕ (IMU GY-LSM6DS3)
Важно: используется знаковая функция bytesToInt()
------------------------------------------------------------------------

16. Ускорение по оси X - Accel X (Продольное / боковое)
    Packet ID : 0x103 (или 259)
    Единицы   : G (диапазон +-8.000 G)
    Equation  : bytesToInt(raw, 0, 2) * 0.001

17. Ускорение по оси Y - Accel Y (Боковое / продольное)
    Packet ID : 0x103 (или 259)
    Единицы   : G (диапазон +-8.000 G)
    Equation  : bytesToInt(raw, 2, 2) * 0.001

18. Вертикальное ускорение - Accel Z (В покое около 1.00 G)
    Packet ID : 0x103 (или 259)
    Единицы   : G (диапазон +-8.000 G)
    Equation  : bytesToInt(raw, 4, 2) * 0.001

19. Угловая скорость рыскания / заноса - Yaw Rate (Gyro Z)
    Packet ID : 0x103 (или 259)
    Единицы   : deg/s (градусов в секунду, +-500 deg/s)
    Equation  : bytesToInt(raw, 6, 2) * 0.1


------------------------------------------------------------------------
ПАКЕТ 0x104 (PID: 260) — ГОТОВЫЕ ТЕМПЕРАТУРЫ NTC (В °C) И ГИРОСКОП X/Y
Важно: используется знаковая функция bytesToInt()
------------------------------------------------------------------------

20. Готовая температура воды - T_WATR (NTC кривая: R25=2500 Ом, Beta=3900)
    Packet ID : 0x104 (или 260)
    Единицы   : C (Градусы Цельсия с точностью 0.1 C)
    Equation  : bytesToInt(raw, 0, 2) * 0.1

21. Готовая температура масла - T_OIL (NTC кривая: R25=2500 Ом, Beta=3900)
    Packet ID : 0x104 (или 260)
    Единицы   : C (Градусы Цельсия с точностью 0.1 C)
    Equation  : bytesToInt(raw, 2, 2) * 0.1

22. Скорость крена - Roll Rate (Gyro X)
    Packet ID : 0x104 (или 260)
    Единицы   : deg/s (градусов в секунду)
    Equation  : bytesToInt(raw, 4, 2) * 0.1

23. Скорость тангажа / клевка - Pitch Rate (Gyro Y)
    Packet ID : 0x104 (или 260)
    Единицы   : deg/s (градусов в секунду)
    Equation  : bytesToInt(raw, 6, 2) * 0.1


========================================================================
   ГОТОВЫЕ ФОРМУЛЫ ДЛЯ ДАТЧИКОВ 0..5 В НА ВХОДАХ AIN1 И AIN2 (0x100)
   (Питание датчика: +5V_OUT с X5 пин 1, Масса: AGND с X5 пин 6)
========================================================================

* Датчик давления 0..10 Бар (выход 0.5..4.5 В) на входе AIN1:
  Equation: (bytesToUint(raw, 4, 2) * 0.001 - 0.5) * 2.5

* Датчик давления 0..7 Бар / 100 PSI (выход 0.5..4.5 В) на входе AIN1:
  Equation: (bytesToUint(raw, 4, 2) * 0.001 - 0.5) * 1.75

* Датчик положения дросселя TPS 0..100% (выход 0.5..4.5 В) на входе AIN2:
  Equation: clamp((bytesToUint(raw, 6, 2) * 0.001 - 0.5) * 25.0, 0, 100)


========================================================================
       УПРАВЛЕНИЕ ПЛАТОЙ ПО BLUETOOTH LE (СЕРВИСНЫЕ ХАРАКТЕРИСТИКИ)
========================================================================
Основной сервис UUID: 00000001-0000-00fd-8933-990d6f411ff8

* Характеристика 0x05 (OTA DFU - Обновление прошивки):
  Записать 2 последних байта MAC-адреса устройства -> вход в DFU режим.

* Характеристика 0x06 (Управление ключами DOUT1 и DOUT2):
  Отправить 2 байта (Hex):
  01 01  -> Включить выход DOUT1 (замкнуть X2 пин 3 на GND_OUT)
  01 00  -> Выключить выход DOUT1
  02 01  -> Включить выход DOUT2 (замкнуть X2 пин 4 на GND_OUT)
  02 00  -> Выключить выход DOUT2
